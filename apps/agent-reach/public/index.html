Agent Reach Channel Explorer

Agent Reach 是一个 MIT 开源的能力层（capability layer）：它替 AI Agent 选型、安装、体检、路由各平台最稳的上游 CLI，让 Agent 能读取和搜索整个互联网。 它不是托管 API，也不是读取包装层——装好之后，Agent 直接调用上游工具 （Jina Reader、gh、yt-dlp、feedparser、Exa……）。 agent-reach doctor 一条命令告诉你每个渠道当前走哪个后端。
